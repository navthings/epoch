# epoch

wip, epoch is a simple playground for learning how neural networks learn

# feature list
1. onboarding
    onboarding explaining all the steps, think brilliant style.
    
2. dataset
    using a small ~15% split of MNIST, so you can draw your own number and see what the model YOU created think

3. customiseability + interaction
    set the number of epochs, customise the size of the model, experiment with different training splits, see the training in action

4. math
    every step is beautifully written out in math, so you can understand whats really happening

while staying aesthetic, and useful, asw as following law of effect by Edward Thorndike.

# story
actually have a good story behind this one

learning ml sucks.

at least at the beginning.

there are tutorials that take 50 hours. there are courses that assume you already know half the maths. there are notebooks where you can train a model in five lines, but you don't really learn what's happening.

and the annoying part is that ml gets fun at exactly the point where learning it stops being fun.

once you can actually make something, you want to keep going. you train a model, change something, see what happens, break it, fix it, try again.

but getting to that point is the hard part.

this reminded me of Edward Thorndike's law of effect: behaviours followed by satisfying results are more likely to be repeated.

which makes learning ml feel backwards.

you're asking someone to spend hours learning things they don't yet find rewarding, so that eventually they can reach the part that's rewarding enough to make them want to learn more.

so this tries to fix that :)
